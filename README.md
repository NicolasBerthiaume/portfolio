# nicolasberthiaume.com

My personal portfolio site. Live at [nicolasberthiaume.com](https://nicolasberthiaume.com).

## Built with
- Plain HTML, CSS and JavaScript, with no frameworks
- GitHub Actions for CI/CD, with separate build and deploy jobs
- GitHub Pages for hosting, with Cloudflare DNS

## Run locally
Open `index.html` in a browser. There's nothing to install.

## Deploy
Every push to `main` builds and deploys automatically.
